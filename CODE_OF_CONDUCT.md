# Conduct

This is a small research project. A few plain rules cover the issue tracker and any other place where
the project is discussed under its name.

1. **Argue about claims, not about people.** Say what is wrong and show why. Do not comment on who
   someone is, where they work or studied, or how they write.
2. **Bring evidence.** A counterexample, a command with its output, or a reference settles more than
   an opinion. If you are unsure, say so; that is useful too.
3. **Credit earlier work.** If something here was done before, point to it. Nobody will be treated
   badly for showing that a result is not new.
4. **No harassment.** No insults, threats, sexual remarks, or publishing someone's private
   information. No pile-ons, here or elsewhere, in this project's name.
5. **AI-assisted work is discussed on its merits.** This repository was produced with an AI system and
   says so. Reports made with such systems are welcome when they can be reproduced. Whether a result
   is right does not depend on how it was produced, and it is still fair to ask how.

The maintainer may edit, hide or remove contributions that break these rules and may block repeat
offenders. To report a problem privately, write to 0_0@0thernes.art.
