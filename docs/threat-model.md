# Threat Model

- **Statement weakening / vacuity:** Mitigated by isolated `lean/Challenge.lean` <-> `lean/Solution.lean` with 6 comparator targets: both halves of each main theorem (`target_box3h2_minimum_31`, `target_box4h1_minimum_18`), independent basis-bearing 30-ray and 17-ray explicit 0/1 colouring witnesses (`target_box3h2_nonvacuous_30`, `target_box4h1_nonvacuous_17` via `KS.isColoring_of_isColoringBool`, closing `ERRATA.md` K1), and kernel-proved refutations of perturbed headline bounds (`target_box3h2_refute_30`, `target_box4h1_refute_17`, closing `ERRATA.md` K2). Statements are accepted via `lake comparator --paranoid` by the official Lean kernel (default and paranoid mode) and four external checkers.
- **Single-kernel bug:** Mitigated by multi-kernel replay (`leanchecker-paranoid`, `lean4lean`, `nanoda`, `con-leche`, `con-ron`).
- **Home-grown DRUP checker (`verify/drup_check.c`):** Compiled with `-Wall -Wextra -Wpedantic -fsanitize=address,undefined` in CI, cross-checked against pinned, SHA-256-verified upstream `drat-trim` → LRAT → `lrat-check` **and HOL4-formally-verified `cake_lpr`** (`scripts/verify_lrat.sh`) for **5 pools / 6 UNSAT proofs** (`B(3,2)`, `B(4,1)`, `B(3,3)`, `U(3,6)` minimum + uniqueness, and `U(3,12)`) in CI, and tracked for full `cake_lpr` replay of all 83 dim-5 cubes in `ROADMAP.md`.
- **Tampering / retroactive dating:** Mitigated by `data/MANIFEST.sha256` sealed with both DigiCert RFC 3161 TSA (`data/MANIFEST.sha256.tsr`, OpenSSL X.509 verified in Linux CI) and 3-calendar Bitcoin OpenTimestamps (`data/MANIFEST.sha256.ots`), Sigstore/Rekor SLSA release attestations, and Software Heritage snapshots (`swh:1:snp:68ed4cd5af45b8fa4ed21a82f8f3dfd69ac901ae`).
